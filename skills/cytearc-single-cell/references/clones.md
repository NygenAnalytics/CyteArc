# Clones and lineage tracing

Import the clones that a lineage tracing tool or a study assigned to cells, or the lineage barcodes that clones are called from and call the clones, join them to the store's cells, check how many barcodes joined, see how large the clones are, measure clonal expansion and diversity within samples or other groups of cells, compare groups by the clones they share, measure which fates are coupled, and follow the clones of early cells to the fates they took. Docs: <https://docs.nygen.io/CyteArc/api/clones.html>, <https://docs.nygen.io/CyteArc/analysis_with_agents.html>.

## When to use

- A file that lists each cell's clone: CoSpar's `Cell_ID,Clone_ID` table, TREX's `clones.txt`, CellTag-multi's or CellTagR's clone table, STICR's Cell Browser `meta.tsv`, Cassiopeia's allele table (`lineageGrp`), Numbat's `clone_post_{i}.tsv`, LARRY's GEO clone matrix with its metadata, an AnnData file with CoSpar's `obsm['X_clone']` or MiTo's `obs['MiTo_clone']`, or any table with a cell and a clone column.
- A cell metadata column that already holds each cell's clone: `ds.clones.from_column`.
- Immune receptor clonotypes from `ds.repertoire.clonotypes` (see `immune-repertoires.md`): every function below takes a `clonotypes` artifact as it takes `clones`.
- A file that lists barcodes per read, molecule or cell without clone IDs (TREX `molecules.txt`, pycashier, CellTag-multi's per-read tables, FateMap, QuiCAT, BARtab counts, Cell Ranger `molecule_info.h5`), or an assay of barcode counts: `ds.clones.import_barcodes`, which keeps every molecule and barcode for clone calling.
- Clones from imported lineage barcodes: `ds.clones.barcode_clones` with the preset of the method that made them (LARRY, TREX, CellTagR, CellTag-multi) or rules chosen one by one.

## Key concepts

- `ds.clones.import_clones(paths, *, cell_selection, barcode_prefix=None, barcode_suffix=None, barcode_pattern=None, format=None, columns=None, multiple="error", invalidate_cache=False)` saves a datastore-scoped `clones` artifact. The format comes from the file: HDF5 is AnnData, `%%MatrixMarket` a clone matrix, and a text header names the tool. `format` is one of `"cospar"`, `"trex"`, `"celltag_multi"`, `"celltagr"`, `"sticr"`, `"cassiopeia"`, `"numbat"`, `"table"`, `"matrix"`, `"cospar_h5ad"`, `"mito"`, `"h5ad"`.
- `columns={"cell": ..., "clone": ..., "probability": ...}` reads any other table (format `"table"`) or an AnnData `obs` column (`"h5ad"`, clone and probability only). `"cell"` may list columns joined by `"__"`, as LARRY's `["Library", "Cell barcode"]`. A table with R row names (header one field shorter than its rows, such as the Biddy workflow's `celltag_data.txt`, or a first column with an empty name, as `write.csv` writes) takes cells from the row names, so `columns={"clone": "CellTagD13"}` reads one labelling round. Blank lines hold no rows. A table whose every row ends in its delimiter, one field more than its header with nothing in the last, is refused, since R's row names with an empty last column read alike; end the header with the delimiter too, or write the row names under a header name (`write.table(..., col.names=NA)`).
- A clone matrix reads its cell list beside it: `<name>metadata.txt.gz` beside `<name>clone_matrix.mtx.gz` (LARRY on GEO), or `cells.tsv` with `clones.tsv` (the export). The axis whose length equals the cell list holds the cells, so LARRY's in vitro (cells by clones) and in vivo and cytokine (clones by cells) files read alike. Unnamed clones are labelled by position from 0.
- The join: a cell's ID is `barcode_prefix + barcode + barcode_suffix`; `barcode_pattern` keeps the named group `barcode` of each barcode (`re.search`), and a barcode it does not match joins no cell. Each option takes one value for every file or one per file. A merged store names cells `<sample>__<barcode>`, so a sample's 10x file needs `barcode_prefix="<sample>__"`, and a TREX file of bare barcodes also `barcode_suffix="-1"`.
- Check the join: the artifact attributes `n_file_barcodes`, `n_unmatched_barcodes` and `unmatched_barcode_examples` count the files' barcodes and those that matched no selected cell, and a warning names up to five; a reused import warns again. Many unmatched barcodes mean a wrong prefix, suffix or pattern, a file of another run, or a selection that left out cells. Non-cell droplets in a file are expected to be unmatched.
- Several files: each file's clone labels start with its `barcode_prefix`, or with its name before the first `.` and `_`, because clone IDs are unique only within one run (TREX numbers clones from 1 in every run). Two files with one namespace, such as two `clones.txt` without prefixes, raise `ValueError`.
- A cell in two different clones raises `ValueError` naming examples; `multiple="drop"` leaves such cells without a clone and counts them in `n_cells_in_several_clones`. Repeated rows of one cell and clone (Cassiopeia lists a cell per target site) count once. Cassiopeia's lineage group 0, MiTo's `"unassigned"`, and empty, `NA`, `NaN` or `nan` labels mean no clone.
- The file's bytes identify it: a moved file reuses the saved clones, an edited one gives new ones, and the order of files does not matter. `invalidate_cache=True` imports again.
- `ds.clones.from_column(column, *, cell_selection, invalidate_cache=False)` saves the clones of a cell metadata column; missing or blank labels mean no clone, and float whole numbers read as integers.
- Memory: the store keeps each cell's label at the width of the longest, so very long labels cost memory for every cell; an import that would not fit `mem_budget` raises `MemoryError` before saving.
- The artifact: canonical `values` (clone label, empty for none), `codes` (clones by size, largest first, then label; -1 for none), `clone_size` (0 for none), and `clone_probability` where the source gives one (Numbat's `p_opt`, or `columns["probability"]`). `ds.select_cells(clones, include=["3"])` selects one clone's cells, and `ds.artifacts.load_values(clones, value="clone_size")` reads the sizes.
- `ds.clones.load_clones(clones)` returns a `Clones` record: `.cells` (indexed by cell ID: `clone` categorical in rank order, `clone_size`, `clone_probability` when stored), `.clones` (`clone`, `n_cells`, largest first), `.source` (`"import_clones"`, `"clones_from_column"` or `"define_clonotypes"`) and `.kept_apart`, the columns of `.cells` whose labels the clones keep apart: `()` for clones, `("receptor_type",)` for clonotypes, whose `.cells` then holds each cell's receptor type.
- `ds.clones.export_clones(clones, path, format="table")` writes CoSpar's `Cell_ID,Clone_ID` CSV; `format="matrix"` writes a cells by clones Matrix Market file with `cells.tsv` and `clones.tsv` beside it, replacing files of those names. Both import back to the same clones; probabilities are not written. The table refuses labels that read as no clone, such as `NA` from `from_column`, and the matrix refuses labels with line breaks: use the other format. Returns the cells written.
- `ds.plots.clone_abundance(clones, group_by=None, groups=None, top=20)` draws clones per clone size on log scales and the largest clones; with a grouping, one line per group and each clone's cells stacked by group. The largest clones are labelled by ID, clonotypes by their representative's junction (`CASSLGQAYEQYF`; `VJ_1` first for `receptor_arms="VJ"`) and also by their number where two drawn share one (`CAVA 1`, `CAVA 3`); for a clonotypes artifact the title reads `Largest 20 clonotypes`, and `Largest 20 clonotype clusters` when a `metric` other than `"identity"` defined it. Tables: `sizes` (`group`, `clone_size`, `n_clones`) and `top` (`clone`, `label`, cells per group).
- `ds.clones.import_barcodes(paths=None, *, cell_selection, from_assay=None, barcode_prefix=None, barcode_suffix=None, barcode_pattern=None, format=None, columns=None, library=None, invalidate_cache=False)` saves a datastore-scoped `lineage_barcodes` artifact (operation `import_lineage_barcodes`). `format` is one of `"trex"` (`molecules.txt`, `molecules_corrected.txt`, every release), `"pycashier"` (with or without header), `"celltag"` (CellTag-multi per-read, ATAC without `UMI`; Biddy parsed reads), `"fatemap"` (with or without header; one sample per file), `"quicat"`, `"quicat_wide"`, `"h5ad"` (cells by barcodes in `X`), `"bartab"`, `"bartab_annotation"` (`;` or legacy `,` lists), `"molecule_info"` (Cell Ranger, one feature barcode library; `library` names its type when several), or `"reads"`, `"molecules"`, `"pairs"` with `columns`. Detected from the header otherwise; TREX's `reads.txt` is refused; clone tables point to `import_clones`.
- Levels: read rows collapse into molecules (reads = rows), or into pairs without UMIs (CellTag ATAC, TREX Smart-seq2); molecule rows keep their reads or -1; pairs keep UMIs and reads, -1 where unknown. Nothing is filtered: errors, one-read molecules and ambient barcodes stay for clone calling. QuiCAT, BARtab, h5ad and `from_assay` counts are read as UMIs; a QuiCAT table of reads needs `format="pairs"` with `columns={..., "reads": "counts"}` (`{"reads": "X"}` for h5ad).
- `columns` roles: `"cell"`, `"barcode"` (one column, or several joined by `"__"`, such as CloneTracker XP's two halves), `"umi"` (molecules need it), `"umis"`, `"reads"`, `"library"`, `"separator"` (`;`, `,`, `:` or `|`; splits a pair's barcode and count lists, kept aligned). Without `"cell"`, R row names are the cells (Watermelon's metadata).
- Libraries: `library` names each file's library (one for every file or one per file; default the file's name before its first `.`; the assay's name with `from_assay`). A library holds molecules or pairs, never both; rows of one library naming one molecule merge, summing reads. Use `library=["RNA", "ATAC"]` for CellTag-multi's two modalities.
- Barcode artifact: canonical `n_barcodes` (distinct barcodes per cell), `n_umis`, `n_reads` (-1 where a library counts none), `n_records`; `record_*` arrays hold one row per molecule or pair. Attributes `libraries` (`library`, `level`, `records`, `has_umis`, `has_reads`), `n_file_rows`, `n_unmatched_rows` (rows read: one per list item, or per nonzero count of a merged table or matrix), `n_empty_rows` (no barcode, or a pair counted 0) and the join's `n_file_barcodes`, `n_unmatched_barcodes`, `unmatched_barcode_examples`.
- `ds.clones.load_barcodes(barcodes)` returns a `LineageBarcodes` record: `.cells` (indexed by cell ID), `.records` (`cell`, `library`, `barcode`, `umi` categoricals, `umi` missing for pairs; `umis`, `reads` nullable `Int64`; a molecule's `umis` is 1), `.libraries`, and `.pairs()` (one row per cell, library and barcode: distinct `umis`, `reads`, `molecules`).
- `ds.clones.barcode_clones(barcodes, *, preset=None, min_reads=None, distance=None, metric=None, allowlist=None, min_umis=None, min_fraction=None, barcodes_per_cell=None, method=None, similarity=None, inclusive=None, prune=None, doublets=None, min_size=None, within=None, invalidate_cache=False)` saves a `clones` artifact (operation `call_barcode_clones`). Rules in order: molecules below `min_reads` dropped; within each `within` group and library, barcodes within `distance` by `metric` (`"hamming"`, `"levenshtein"`) merge into the most abundant of their connected component (ties to the barcode that sorts last); barcodes outside `allowlist` (a sequence of text) dropped; per library, a cell's barcodes below `min_umis` UMIs, or whose UMIs divided by `min_fraction` stay below its top barcode's (BARtab), dropped; cells outside `barcodes_per_cell=(fewest, most)` get no clone; then `method="sets"` (identical barcode sets) or `"jaccard"` (identical sets as nodes, edges between nodes sharing a barcode whose Jaccard index exceeds `similarity`, or reaches it with `inclusive=True`; `similarity=(within_libraries, across_libraries)` for two modalities; `prune` and `doublets` are TREX's bridge and local-cut-vertex rules); connected components are clones; clones below `min_size` cells leave their cells without one.
- Presets: `"larry"` (`min_reads=10`, Hamming 3, `min_umis=3`, sets), `"trex"` (TREX's partial-cloneID rules: entropy below 1 bit dropped, Hamming 5 over the positions both hold a base with at least 20, 20 bases kept, one-UMI cloneIDs shared with other cells or of one read dropped; Jaccard above 0.7, prune, doublets, singletons kept), `"celltag"` (allowlist, `min_umis=2`, 2 to 20 tags, Jaccard above 0.7, clones of 3 or more), `"celltag_multi"` (`min_reads=2`, Levenshtein 2, allowlist, `min_umis=2` (reads for scATAC-seq), 2 to 25 tags, Jaccard above 0.6 within a library and 0.5 across, clones of 2 or more). An argument replaces its preset's value; 0 turns a count filter off. The CellTag presets require `allowlist`; `allowlist=False` calls them without. Without a preset, `method` is required, `"jaccard"` needs `similarity` and `inclusive`, and `distance` needs `metric`.
- Counts are read in each library's unit: a molecule is one UMI; a pair counts UMIs, or reads in a library with no UMIs for any pair (CellTag-multi scATAC-seq). A library with UMIs for some pairs only has no unit. Rules refuse counts they cannot read: `min_reads` needs every molecule's reads (pairs pass it; all-pair barcodes are refused), correction and pair filters a unit per library, TREX's rules molecules with reads (TREX writes `read_count` since 2024-09). `method="sets"` alone reads no count.
- Barcode clones: labels `clone_1` (largest) on; arrays `n_barcodes` (after pair filters) and `doublet`; attributes `rule_counts` (what each rule removed or changed: `molecules_below_min_reads`, `barcodes_corrected`, `records_outside_allowlist`, `pairs_below_min_umis`, `cells_outside_barcodes_per_cell`, `nodes`, `edges`, `edges_pruned`, `doublets`, `cells_in_small_clones` and TREX's), `library_units` and `diagnostics`: `distinctBarcodes` (compared after the molecule filters, per `within` group and library; TREX's cloneIDs under 20 bases excluded), `expectedChanceMatches` (pairs of them within `distance` by chance, from each position's base frequencies among them: exact under that independence for Hamming, an approximation for Levenshtein), `mergedBarcodes` (equals `barcodes_corrected`), `largestCloneShare` (largest clone's cells over the cells given a clone, 0 without clones); 0 expected and merged at `distance=0`. `load_clones(...).diagnostics` returns them as a dict (empty for other sources). `metric="levenshtein"` takes `distance` at most 8. `load_clones(...).cells` gains `n_barcodes` and `doublet`; `.source` is `"call_barcode_clones"`. Every summary reads the artifact as it reads imported clones.
- `ds.plots.barcode_calls(barcodes, max_barcodes=10)` draws cells by barcodes per cell, pairs by UMIs per barcode and molecules by reads per molecule, per library. Tables: `barcodes_per_cell`, `umis_per_barcode`, `reads_per_molecule`.
- Summaries take `clones, *, group_by=None, groups=None, cell_selection=None` and count each clone's cells within groups: the combinations of the `group_by` columns' labels and the `groups` label artifact's (key column named by its kind, such as `cluster_labels`). Cells without a clone or a label count in no group, and when no cell has both, every summary raises `ValueError`. Clonotypes keep each receptor type apart: `receptor_type` joins the key columns, so a sample's T cells and B cells are two groups (`"s1, TCR"`, `"s1, BCR"`), and the groups without a grouping are the receptor types; `group_by="receptor_type"` is refused. The abundance plot groups clonotypes alike. A group is named by its labels joined by `", "`, or `"all cells"`; labels with commas that give two groups one name, and a key column named like a column of the result, raise `ValueError`.
- `ds.clones.expansion(clones, group_by=None, groups=None, cell_selection=None, breakpoints=None, frequency_breakpoints=None, invalidate_cache=False)` saves a datastore-scoped `clonal_expansion` artifact (operation `measure_clonal_expansion`) of the cells of `cell_selection`, or of the clones' cells; a selected cell the clones do not hold has no clone. Pass at most one bound: `breakpoints`, default `(1, 2, 5, 20, 100)`, gives `"1 cell"`, `"2 cells"`, `"3 to 5 cells"`, `"6 to 20 cells"`, `"21 to 100 cells"`, `"more than 100 cells"` (scirpy's `clonal_expansion`); `frequency_breakpoints` (bins `(lower, upper]` ending at 1, such as scRepertoire's `(0.0001, 0.001, 0.01, 0.1, 1)`) bins each clone's share of its group's cells with a clone.
- Expansion arrays: canonical `values` (category, empty without a clone or group), `group_clone_size`, `group_clone_frequency`, `group_codes`. `select_cells(expansion, include=["21 to 100 cells", "more than 100 cells"])` keeps the cells of large clones. Reuse follows the clones, cells, label artifact, bounds and each cell's `group_by` labels. Every summary checks the memory budget before it reads: about 300 bytes per cell to measure expansion and 500 to load it beside the cells' IDs as text, 100 per cell to group plus three times the stored width of each `group_by` column's labels, and 2,000 per group, so a label for each cell costs far more than the cells; the clones API page lists every step.
- `ds.clones.load_expansion(expansion, splits=(10, 100, 1000, 10000, 30000, 100000))` returns a `ClonalExpansion` record: `.cells` (`clone`, `category` (ordered), `group`, the key columns, `group_clone_size`, `group_clone_frequency`; labels are categoricals), `.categories` (`group`, key columns, `category`, `cells`, `clones`, `fraction`; every category of every group), `.rank_windows` (`group`, key columns, `window` such as `"1 to 10"`, ..., `"after 100000"`, `cells`, `fraction`: scRepertoire's `clonalProportion`), `.labels`, `.breakpoints`, `.frequency_breakpoints`, `.splits`, `.group_by`, `.groups`, `.cell_selection`, `.clones`.
- `ds.plots.clonal_expansion(expansion, group_by=None, groups=None, count="cells", normalize=True, splits=...)` draws stacked bars per group of the categories (cells, or `count="clones"`) and of the rank windows. Groups default to the expansion's own; `group_by`/`groups` regroup the cells (categories stay those measured within the expansion's groups; ranks are recounted within the plotted groups, and clonotypes' receptor types stay apart, as in `"blood, TCR"`). Tables: `categories` (`group`, `category`, `cells` or `clones`, `fraction`), `rank_windows` (`group`, `window`, `cells`, `fraction`).
- `ds.clones.diversity(clones, group_by=None, groups=None, cell_selection=None, size=None, coverage=None)` returns a `ClonalDiversity` record and saves nothing: `.indices`, one row per group (`group`, key columns, `cells`, `clones`, `singletons`, `doubletons`, `coverage`, `shannon` in nats, `pielou`, `simpson`, `inverse_simpson`, `gini_simpson`, `gini`, `d50`, `chao1`, `chao1_bias_corrected`, `ace`), and `.hill`, one row per group and order 0, 1, 2 (`observed`, `estimated` asymptotic, `at_size`, `coverage_at_size`, `method_at_size`, `at_coverage`, `size_at_coverage`, `method_at_coverage`; methods `"rarefaction"`, `"observed"`, `"extrapolation"`), with `.size` and `.coverage`, by default iNEXT's smallest doubled size and lowest coverage at doubled sizes. `cytearc.clones.ORDERS` is `(0, 1, 2)`.
- `ds.clones.rarefaction(clones, group_by, groups, cell_selection, orders=(0, 1, 2), sizes=None, endpoint=None, knots=40)` returns a `Rarefaction` record: `.curves` (`group`, key columns, `order`, `size`, `method`, `diversity`, `coverage`); default sizes are iNEXT's 40 knots per group (half up to its size, half to twice it); `sizes` gives every group the same sizes.
- `ds.plots.clonal_rarefaction(clones, group_by=..., cell_selection=..., orders=(0, 1, 2), base="size" or "coverage")`: one panel per order (`order_0`, `order_1`, `order_2`) plus `coverage` (sample completeness) with `base="size"`; solid rarefied, dashed extrapolated, a point at the observed size. Table: `curves`.
- `ds.clones.overlap(clones, group_by=None, groups=None, cell_selection=None)` returns a `CloneOverlap` record and saves nothing; at least two groups must hold a cell with a clone. `.group_sizes`: `group`, key columns, `cells`, `clones`. `.pairs`, one row per pair of groups: `group_1`, `group_2`, `shared`, `jaccard`, `sorensen`, `overlap` (shared over the smaller group's clones), `cosine` (of presence), `morisita_horn`, `abundance_cosine` (of clone sizes), `shared_fraction_1`, `shared_fraction_2` (the share of each group's cells whose clone the other holds). `cytearc.clones.OVERLAP_INDICES` names the indices. Memory: about 250 bytes per pair of groups; `track` about 100 bytes per row and 16 per row for each key column.
- `ds.clones.track(clones, group_by, groups, cell_selection, top=10, labels=None)` returns a `CloneTracking` record: `.tracked` (labels, largest first) and `.cells`, one row per chosen clone and group, zeros included: `clone`, `group`, key columns, `cells`, `fraction` (of the group's cells with a clone). By default the union of each group's `top` largest clones (scRepertoire's `clonalCompare`; ties to the larger clone overall); `labels` names clones instead.
- `ds.plots.clonal_overlap(clones, group_by=..., index="morisita_horn")` draws one index as a heatmap of the pairs (values printed for at most 12 groups, group names for at most 40; tables `matrix`, `pairs`); `ds.plots.clone_tracking(clones, group_by=..., top=10, labels=None, order=None)` draws one line per clone of its share of each group's cells, labelled as in `clone_abundance` (`order` may hold numbers, such as time points; the legend lists at most 80 clones, largest first; table `cells`).
- `ds.clones.coupling(clones, *, group_by=None, groups=None, cell_selection=None, method="share_cosine", permutations=1000, seed=0)` returns a `CloneCoupling` record and saves nothing; at least two groups must hold a cell with a clone. `method` follows CoSpar's `fate_coupling` on a clone matrix: `"share_cosine"` (default; CoSpar's `"SW"` with `normalize=True`: cosine of each group's shares of each clone, every clone counted once), `"abundance_cosine"` (`"SW"`, `normalize=False`; overlap's index), `"normalized_covariance"` (`"Weinreb"`, `normalize=False`; below 0 when groups share fewer clones than chance), `"jaccard"`. `cytearc.clones.COUPLING_METHODS` names them. `.pairs`: `group_1`, `group_2`, `coupling`, `null_mean`, `null_sd`, `z_score`; the null shuffles group labels of the cells with a clone (keeps clone and group sizes), each permutation from a stream keyed by `seed`, so results do not depend on `nthreads`. `.group_sizes` (`group`, key columns, `cells`, `clones`), `.order` (average-linkage leaf order, most coupled together), `.linkage` (SciPy linkage of the `group_sizes` positions), `.method`, `.permutations`, `.seed`. `permutations=0` skips the null, and the heatmap of its z-scores is refused; 1 is refused. `seed` lies below 2**64. Memory: about 250 bytes per pair, 40 per product of two groups, and per thread 4 per cell with a clone and 8 per product of two groups; a tight budget runs the null on fewer threads.
- `ds.clones.fate_bias(clones, *, group_by=None, groups=None, early, late, invalidate_cache=False)` saves a datastore-scoped `clone_fate_bias` artifact (operation `measure_clone_fate_bias`) labelling the `early` cells (a cell selection) with their dominant fate; fates are the groups of the `late` cells (a cell selection sharing no cell with `early`). Per early cell: `values` (dominant fate, empty for none or a tie), `codes` (clone), `fate_codes`, `late_cells` (its clone's late cells), `fractions` (cells by fates, NaN without late cells; CoSpar's `fate_map(method="sum")` on its clonal transition map). Per clone with late cells: counts per fate and a one-sided Fisher test per fate against all late cells with a fate (CoSpar's `clonal_fate_bias(alternative="less")`, which is the upper tail), Benjamini-Hochberg within each fate (CoSpar adjusts within clone sizes). A fate named `clone`, `late_cells` or `fate` is refused.
- `ds.clones.load_fate_bias(bias)` returns a `CloneFateBias` record: `.cells` (indexed by early cell ID: `clone`, `late_cells`, `fate`, then one column per fate of its share), `.clone_fates` (one row per clone with late cells and fate: `clone`, `fate`, key columns, `early_cells`, `late_cells`, `cells`, `fraction`, `p_value`, `q_value`), `.fates` (`fate`, key columns, `late_cells`), `.clones`, `.early`, `.late`, `.group_by`, `.groups`. `ds.select_cells(bias, include=["Neutrophil"])` keeps early cells whose clones went mostly to neutrophils.
- `ds.plots.clone_coupling(coupling, value="z_score")` draws the record as a heatmap in its linkage order with the tree above (z-scores centred on 0; `value="coupling"` for the values; tables `matrix`, `pairs`); `ds.plots.clone_fates(bias, top=40, normalize=False)` stacks the late cells of the `top` clones with the most late cells by fate, grouped by dominant fate, under their early cells (table `clones`).
- Validated on immune receptor clonotypes: every cell's category equals scirpy 0.25.1's `clonal_expansion`, frequency fractions equal scRepertoire 2.8.0's `clonalHomeostasis` and rank windows its `clonalProportion`; Hill-number curves within 1.4e-12 of iNEXT 3.0.2, `estimateD` within 1e-7, every index within 6e-14 of scRepertoire 2.8.0 `clonalDiversity`, immunarch 0.10.3 `repDiversity` and vegan 2.7.6 `estimateR`; every overlap index within 5e-14 of immunarch 0.10.3 `repOverlap` and scRepertoire 2.8.0 `clonalOverlap`.

## Recipe

```python
cells = ds.snapshot_cell_selection("I")
# One TREX run per sample, with bare 10x barcodes, in a merged store.
clones = ds.clones.import_clones(
    ["d2/clones.txt", "d4/clones.txt"],
    cell_selection=cells,
    barcode_prefix=["d2__", "d4__"],
    barcode_suffix="-1",
)
attributes = ds.artifacts.load(clones).attrs
print(attributes["n_unmatched_barcodes"], "of", attributes["n_file_barcodes"], "barcodes unmatched")
table = ds.clones.load_clones(clones)
table.clones.head(10)
ds.plots.clone_abundance(clones, group_by="sample")
expansion = ds.clones.expansion(clones, group_by="sample")
ds.clones.load_expansion(expansion).categories  # cells and clones per sample and category
ds.plots.clonal_expansion(expansion, group_by="cell_type", show=False).save("clonal_expansion.png")
diversity = ds.clones.diversity(clones, group_by="sample")
print(diversity.indices[["sample", "cells", "clones", "coverage", "shannon", "inverse_simpson", "chao1"]])
```

## Checks

- Compare `n_unmatched_barcodes` with what the file should hold outside the selection before suspecting the prefix, suffix or pattern. pycashier, BARtab from BAM input and Cell Ranger's molecule info list droplets that are not cells, so their unmatched barcodes are expected.
- After calling barcode clones, read `rule_counts`: a rule that removed most molecules or barcodes, such as LARRY's `min_reads=10` on a shallow library, needs a lower threshold, given alone with the preset. LARRY's identical sets split clones whose cells lost a barcode, and so does TREX's pruning when the cells lost different barcodes; the CellTag presets keep them together.
- Then read `load_clones(clones).diagnostics`: `expectedChanceMatches` near or above a nonzero `mergedBarcodes` means correction merges unrelated barcodes, and above about a tenth of `distinctBarcodes` it chains barcodes into large clones (chance matches grow with the square of the barcodes compared; TREX's rule on synthetic clones: 0.30 per compared cloneID at 200k cells gave a 1,393-cell clone, 1.5 at 1M put 4 in 5 cells in one clone). A `largestCloneShare` far above the next clones' suggests the same chaining. The bases' frequencies come from one barcode per component of correction, so merged errors do not weigh in (TREX's 10x test output, 7 components: 0.07 expected, 89 merged); with one to three components in a group and library the expectation is unreliable in both directions, so judge the largest clone against the experiment. Lower `distance`, or pass `within`, and compare the clones.
- After a barcode import, check `loaded.libraries`: each library's `level` and whether it counts UMIs and reads decide which filters clone calling can apply. Most cells should hold a few barcodes in `plots.barcode_calls`; one-read molecules and one-UMI barcodes are mostly errors and ambient reads.
- Check `table.clones["n_cells"]` against the study's reported clone count and sizes; LARRY's in vitro and cytokine sets hold only clones of two or more cells, while TREX keeps singletons.
- With several files, check that `table.clones["clone"]` carries each file's namespace, and that clones expected to span samples were called jointly in one run; clones of separate runs never merge.
- Measure expansion and diversity `group_by` the sample: without it, a clone's cells in all samples add up. Frequency categories depend on sample size (one cell of 1,000 is already 0.001), so compare them only between samples of similar size; bounds in cells compare any samples.
- Compare diversity by Hill numbers at a common coverage or size (`hill.at_coverage`, `hill.at_size`), not observed indices, which grow with the cells sampled. Check `plots.clonal_rarefaction`: steep curves at the observed point mean richness and Chao1 are poorly determined; order 2 is stable. Name the Chao1 form reported. Leave out tiny groups with `cell_selection`, or set `size`/`coverage`, since the smallest group sets the defaults.
- Read overlap by the Morisita-Horn index and the shared fractions; presence indices (Jaccard, Sørensen, overlap, cosine) grow with both groups' cells, so compare them only between pairs of similar depth. A clone seen in one group only may be below detection in the others.
- Measure coupling on the cells of one time point (`cell_selection`) and read `z_score` as a ranking: shuffled labels spread each clone over every group, so when clones commit to few fates most pairs fall below the null. Keep `share_cosine` unless a few large clones should dominate. Coupling treats cells as exchangeable: it is exploratory within one sample.
- For fate bias, `early` and `late` must share no cell. Every early cell of a clone gets its clone's fractions, so summarise by clone; report how many early cells have late clone-mates. Small clones cannot reach small p-values. When barcode detection differs between cell types, pass only late cells with a clone as `late`.
- Compare conditions with one value per sample (such as the fraction of cells in clones of more than two cells), never with cells as replicates; test such values with a method that treats samples as replicates, such as CytePool's (https://docs.nygen.io/CytePool/).
